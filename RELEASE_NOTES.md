### 🐧 Experimental Linux Support

* **Native Linux builds**: Standalone Linux packages are now automatically compiled and published alongside Windows releases.
* **Automatic platform detection**: The updater automatically detects whether you are on Windows or Linux and downloads the correct package.

---

### 🔧 Source Code Updates & Reliability

* **Seamless Git updates**: Running from source code now updates cleanly using Git and automatically syncs dependencies without redownloading entire releases.
* **No more file locking crashes**: Updating from source on Windows no longer crashes with permission errors when replacing active files.
* **Protected personal settings**: Your custom configuration files, Python virtual environments, and download history are strictly protected and never overwritten during updates.

---

### ⚙️ Watchlist Enhancements

* **Apply current settings to updates**: New toggle in Watchlist settings to apply your active global filters and options when updating saved creators instead of using outdated settings.
* **Smooth batch queueing**: Updating multiple creators at once now queues sequentially to prevent connection congestion and ensure steady downloads.
